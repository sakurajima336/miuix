## ② COUITabLayout 套件（标签页，coui-core 无对应物）⭐⭐⭐

类（`com.coui.appcompat.tablayout`）：`COUITabLayout`、`COUISlidingTabStrip`（实际指示器容器）、`COUITab`、`COUITabItem`、`COUITabView`、`COUITabLayoutMediator`、`COUIFragmentStatePagerAdapter`、`COUIPercentTabWithSearchView`、`COUIAnimationUtils`。

### 功能
Google Material TabLayout 的 COUI 深改版：文字 Tab 的指示器不是简单平移，而是**宽度随移动方向拉伸/收缩的"果冻"动画**，同时新旧 Tab 文字颜色做 ArgbEvaluator 交叉渐变；支持红点/数字角标（`COUITab.setPointMode/setPointNumber`，字段 `mDotHorizontalOffset`、`mDotVerticalOffsetFromNumberRed`、`mDotVerticalOffsetFromOnlyRed`）、加粗选中（`setBold`）、振动（`setEnableVibrator`）、左右附加按钮（`addButton(Drawable, OnClickListener)` 等 4 个重载，内部 `PrivateButton`）、`setupWithViewPager(ViewPager1)` + `COUITabLayoutMediator`、Tab/TabView 双池复用（`TAB_POOL = Pools.SynchronizedPool(16)`，`mTabViewPool`）。

### 关键源码

**指示器动画时长**（`COUITabLayout.getIndicatorAnimTime`，rea/tl_animtime.json）：
```java
public int getIndicatorAnimTime(int i, int i2) {
    return Math.min(300, (Math.abs(i - i2) * 50) + 150);   // 相邻 200ms，≥3 格封顶 300ms
}
```

**文字 Tab 指示器动画**（`COUISlidingTabStrip.animateIndicatorToPosition`，rea/tl_animInd.json）：
```java
valueAnimator3.setDuration(indicatorAnimTime);          // 上面公式
valueAnimator3.setInterpolator(new COUIEaseInterpolator());
// 宽度拉伸：fraction 增大时 width = 旧宽 + Δ宽*f；方向反转(f 递减)时对称收缩
i11 = (int)((i7-i6) + (i8*animatedFraction));           // i8 = 目标宽-当前宽
i12 = (int)(i6 + (i9*animatedFraction));                // i9 = 目标left-当前left
setIndicatorPosition(i12, i11+i12);
// 文字颜色：ArgbEvaluator 双向渐变（新 tab →选中色，旧 tab →普通色）
```
- 非 customView 的 icon Tab 分支用 `COUIAnimationUtils.FAST_OUT_SLOW_IN_INTERPOLATOR` + 固定 300ms + `COUIAnimationUtils.lerp`。
- **跨格跳跃**：`|Δposition| > 1` 时不从当前位置出发，而是从目标边缘外 `dpToPx(24)`（24dp）处飞入。

**滑动手势逐帧跟随**（`COUISlidingTabStrip.updateIndicatorPosition`，rea/tl_updInd.json）：`setScrollPosition(pos, offset)` 时指示器 left/right 在当前 tab 文字边界（±`getIndicatorPadding()`）与下一 tab 文字边界之间按 `mSelectionOffset` 插值，宽度和位置同时线性过渡；用 `mLastSelectionOffset` 检测方向反转并切换插值分支。

**点击切换**（`COUITabLayout.animateToTab`，rea/tl_animTab.json）：内容滚动用复用的 `mScrollAnimator`（IntEvaluator），指示器固定 300ms。

**TabView 触摸/选中态**（`COUITabView.configStateEffectBackground`，rea/tl_statefx.json）：
```java
setDefaultFocusHighlightEnabled(false);
mMaskEffectDrawable = new COUIMaskEffectDrawable(getContext(), 1);
mMaskEffectDrawable.setMaskRect(mTabRect, dpToPx(8), dpToPx(8)); // 8dp 圆角掩膜
mMaskEffectDrawable.enableSelectedState(false);
mMaskEffectDrawable.setMinProgressForTouchEnterAnimation(0.0f);
mStateEffectBackground = new COUIStateEffectDrawable(new Drawable[]{背景, mMaskEffectDrawable});
COUIDarkModeUtil.setForceDarkAllow(this, false);
```
即按压缩放光效由 `COUIMaskEffectDrawable`（COUI 通用按压效果库）实现，掩膜矩形 = tab 内容区 + 8dp 圆角。

**布局细节**（`COUITabView.updateTextAndIcon`，rea/tl_updTI.json）：图+文时图标 bottomMargin=dpToPx(8)；纯图标时用 `TooltipCompat.setTooltipText`；文字变化时 post 触发 strip 重新测量。

**插值器库**（`COUIAnimationUtils` 字段，rea/tl_animutils.json）：`DECELERATE / FAST_OUT_LINEAR_IN / FAST_OUT_SLOW_IN / LINEAR / LINEAR_OUT_SLOW_IN` + `lerp` + `getScaleStandard`。

### KMP Compose 移植要点
- 指示器用 `Animatable<Float>` 自绘：状态 = (left, width)，宽度按方向差值生长；`200~300ms` 时长随距离伸缩；`COUIEaseInterpolator` 对应 Compose 中自写 Easing（贝塞尔反推，未确认曲线参数）。
- 逐帧拖动跟手：pager offset 驱动，不需要动画器。
- 红点/加粗/角标间距等常量字段存在但数值多由 attr 提供，未逐一确认。

## ③ COUIGridLayout + ResponsiveUI 响应式网格引擎（coui-core 无对应物）⭐⭐⭐

类：`com.coui.appcompat.grid.COUIGridLayout`；引擎在 **`com.coui.component.responsiveui`**：`ResponsiveUIModel`、`ResponsiveUI(Proxy)`、`breakpoints.Breakpoints`、`layoutgrid.LayoutGrid/System/MarginType`、`status.FoldingState(Util)`、`span.SpanUtil`、辅助 `com.coui.appcompat.view.COUIResponsiveGridMaskView`（开发期网格掩膜叠加层，onDraw 画 column/margin 参考）。

### 功能
基于 Oplus 响应式布局系统（window size class + 折叠态）的列网格容器：自动决定列数/边距/间距，支持 4 种模式 `GRID_MODE / SPECIFIC_GAP_MODE / SPECIFIC_SIZE_MODE /（+margin type）`。

### 关键源码

**断点常量**（`Breakpoints.<clinit>` smali，rea/ru_bp_clinit.json）：
- `BP_MEDIUM_WINDOW_BASE_WIDTH = 600dp`（0x258）、`BP_MEDIUM_WINDOW_BASE_HEIGHT = 480dp`（0x1e0）
- `BP_EXPANDED_WINDOW_BASE_WIDTH = 840dp`（0x348）、`BP_EXPANDED_WINDOW_BASE_HEIGHT = 900dp`（0x384）、`BP_EXPANDED_WINDOW_MAXIMUM_WIDTH = 960dp`（0x3c0）

**默认列数**（`COUIResponsiveUtils.getDefaultGridNumbers`，rea/gr_resp_grid.json）：
```java
Compact -> 4 列; Expanded -> 8 列;
MediumLandScape/MediumPortrait/MediumSquare/ExpandedLandPortrait/ExpandedPortrait -> 6 列; 其余 4 列
```

**网格测量**（`COUIGridLayout.calculateInGridMode`，rea/gr_gridmode.json）：
```java
mResponsiveUIModel.rebuild(getMeasuredWidth(), UIUtil.getScreenHeightMetrics(getContext()))
    .chooseMargin(mGridMarginType == 1 ? MarginType.MARGIN_SMALL : MarginType.MARGIN_LARGE);
mGridMargin = model.margin(); mHorizontalGap = model.gutter();
mColumn = model.columnCount() / mChildGridNumber;   // mChildGridNumber = 每个格子占的列数
mChildWidth = model.width(0, mChildGridNumber - 1);
```
`ResponsiveUIModel` 是对 `ResponsiveUIProxy` 的薄封装（`margin()/gutter()` 直接转发，rea/ru_margin.json、rea/ru_gutter.json），实际计算在 `LayoutGridSystem`（该类 inspect 失败：unreadable_output，内部算法未确认）。

**副容器填充**（`COUIResponsiveUtils.calculatePadding`，rea/gr_calcpad.json）：当子项网格数 < 总列数时，左右 padding = margin + (总列-子列)/2 列宽 + (列差/2)*gutter，实现"居中缩进"。

### 百分比容器家族
`COUIPercentWidth{LinearLayout, FrameLayout, RelativeLayout, ConstraintLayout, ListView, RecyclerView}` + `COUIPercentUtils` + `COUIResponsiveUtils`：统一 attr（字段 `mGridNumber/mGridNumberResourceId`、`PADDING_MODE/REMEASURE_MODE`、`LARGE/MEDIUM/SMALL_PADDING`），`setPercentIndentEnabled` / `setIsParentChildHierarchy`，onConfigurationChanged 自动重测；`COUIPercentUtils.calculateWidth/getTotalGridSize` 按屏幕档位（`SMALL/MEDIUM/LARGE_SCRREN_GRID_SIZE`）换算百分比宽。

### COUIListDetailView（平板双栏列表-详情容器，coui-core 无对应物）
`getMainFragmentContainer/getSubFragmentContainer/getEmptyPageFragmentContainer`、`setMainFragmentPercent`、`DEFAULT_MAIN_WIDTH_PERCENT`、`mMin/MaxMainFragmentWidth`、`mGapWidth`、`setDividerColor`、`isInSplitMode()`、onConfigurationChanged 切换分栏/单栏。适合移植为 Compose 的 `ListDetailPaneScaffold` 替代。

## ④ scroll 包：弹簧过滚动 & 对齐吸附套件（coui-core 无对应物）⭐⭐⭐

### SpringOverScroller（+ 内部类 ReboundOverScroller）——弹簧物理 fling
`com.coui.appcompat.scroll.SpringOverScroller` 继承 `android.widget.OverScroller`，真正物理在内部类 `ReboundOverScroller`（rea/sc_rebound.json 类清单）：
- **RK4 数值积分弹簧**：方法 `calculateWithRk4 / calculateOnceWithRebound / update / isAtRest / lostVelocity`；`DEFAULT_DAMPINGRATIO / DEFAULT_STIFFNESS / DEFAULT_TENSION`（值未确认，clinit 为空被内联）。
- **fling→弹簧参数换算**：`getSimulateSplineDistance` 先用原生 spline 模拟出目标距离，再反推弹簧参数使位移吻合；`getDistanceScale(f)`（rea/sc_rb_dscale.json）按初速度缩放模拟距离：≤2000px/s→1.0，10000→0.8，>最高档→0.4，中间线性。
- **摩擦自适应**（`adjustFrictionByStartVelocity`，rea/sc_rb_adjfric.json）：速度在 `(MID_VELOCITY_ADJUST_FRICTION, 10000)` 区间用 `sMidFlingBaseFriction`，更慢用 `sSlowFlingBaseFriction`（常量值未确认）。
- **springBack**（rea/sc_rb_springback.json）：
  ```java
  mSpringBackConfig.setFriction(SpringOverScroller.mSpringBackFriction);
  mSpringBackConfig.setTension(mSpringBackTensionMultiple * 16.0f);  // 张力 = 倍数*16
  ```
- **连续 fling 加速**（`SpringOverScroller.increaseVelocityIfNeed`，rea/sc_incvel.json）：两次 fling 间隔 ≤500ms 且速度 ≥8000 才累计；连续第 5 次起速度乘累积率 `mLastFlingSpeedIncreaseRate *= FLING_SPEED_INCREASE_RATE`，钳位 `[-70000, FLING_SPEED_INCREASE_MAX_VELOCITY]`。
- **Choreographer 驱动**：构造器（rea/sc_spring_init1.json）里 `postFrameCallback` 逐帧回灌时间戳；默认插值器 `COUIViscousFluidInterpolator`（内部类）；联动 `COUlFrameRateScrollSceneHelper` 滚动时提帧率（`setFrameRate(true)`、`setRefreshRate`）。

### 对齐/吸附
- `COUIGradualStopOverScroller` + `COUIGradualStopHelper`：fling 结束时"渐进减速停靠"到中心 item（`findCenterView / getDisplacementToAlignCenter / iterateDisplacement(MAX_ITERATE)`、`springBackToCenter`、`getMaxFlingDistance`）。
- `COUIFlingLocateHelper`：水平 RecyclerView 的居中/起始吸附（`CENTER_ALIGN/START_ALIGN`、`snapToTargetExistingView`、`setCustomSmooth(duration, interpolator)`、`setOnCalculatePreChildDistanceListener`）。
- `COUILocateOverScroller`：带定位的 OverScroller 变体（无弹簧，轻量版）。

### 嵌套滚动仲裁
- `COUINestedScrollableHost.handleInterceptTouchEvent`（rea/sc_host.json）：parent/child 方向相同时 child 可滚则 `requestDisallowInterceptTouchEvent(true)`；正交轴位移乘 **0.5 权重**再比 touchSlop；child 滚不动则放行 parent。通过 `COUIScrollViewProxy` 抽象 6 种视图（`impl/COUIRVScrollViewProxy` RV、`COUISVScrollViewProxy` SV、`COUINSVScrollViewProxy` NestedSV、`COUIVPScrollViewProxy` VP1、`COUIVP2ScrollViewProxy` VP2、`COUICVPScrollViewProxy` CoordinatorLayout+VP），统一 `canScroll(orientation, delta)/getOrientation()`。
- `COUINestedScrollableChild`：接口，child 侧回传。

### 容器本体
`com.coui.appcompat.scrollview.COUIScrollView / COUINestedScrollView / COUIHorizontalScrollView`、`scrollbar.COUIScrollBar`（coui-core 已有 CouiScrollBar 可对照）、`IScrollableView`（仅 `canScroll/getOrientation` 两方法）。

**KMP 移植要点**：Compose 自带 `splineBasedDecay` 无弹簧 fling；需要把 ReboundOverScroller 的"距离反推 stiffness/damping + RK4 + 连甩加速 + 回弹张力=倍数×16"做成 `DecayAnimationSpec`/`Animatable` 扩展；嵌套仲裁可映射到 Compose nested scroll 连接器的 `onPreScroll/onPostScroll`。

## ⑦ COUIBanner 轮播 + COUIPageIndicatorKit 液态圆点指示器（coui-core 无对应物）⭐⭐

### COUIBanner（`com.coui.appcompat.banner`）
类：`COUIBanner`、`COUIBannerRecyclerView`（内部禁 overscroll 的 RV）、`COUIBannerBaseAdapter`、`COUIBannerOnPageChangeCallback`、`COUIBannerUtil`、transformer：`COUIScalePageTransformer`、`COUIMarginPageTransformer`。

**默认值**（`parseAttr`，rea/bn_parseAttr.json）：
```java
couiBannerType: 0(NORMAL)/1(EXPAND); couiAutoLoop 默认 true;
couiLoopDuration 默认 5(秒); couiPageMargin 默认 COUIBannerUtil.DEF_PAGE_MARGIN = dpToPx(24)（rea/bn_util_clinit.json）
screenWidthDp >= 600 时强制 type=EXPAND（双翼模式，mLeftItemWidth/mRightItemWidth 露出两侧页边）
```
**循环**（`startLoopTask`，rea/bn_loop.json）：`postDelayed(loopTask, loopDuration*1000 + mDuration)`（页切换动画时长叠加）；`setInfiniteLoop` 无限轮播 + `setStartPosition`；同时持有 `mViewPager2` 与 `mRecyclerView` 字段（两套实现共存，type 切换）。

**缩放转场**（`COUIScalePageTransformer.transformPage`，rea/bn_scaleTf.json）：中心缩放 + 枢轴向屏幕中心偏移——`|f|>=1` 时 scale=`mMinScale` 且 pivot 靠外缘；`f∈[-1,1]` 时 `scale = minScale + (1-minScale)*(1-|f|)`、`pivotX = width*(0.5 ∓ f*0.5)`。`DEFAULT_MIN_SCALE` 值未确认。

### COUIPageIndicatorKit（Kotlin，粘性"液态"圆点）
**构造器常量**（rea/bn_kitinit1.json）：
```kotlin
DURATION_TRACE_ANIMATION = 300;  STICKY_DISTANCE_FACTOR = 2.95f;  DISTANCE_TURN_POINT = 2.8f
BEZIER_OFFSET_SLOPE = -1f; BEZIER_OFFSET_INTERCEPT = 3f; BEZIER_OFFSET_MAX_FACTOR = 1f
BEZIER_OFFSET_X_SLOPE = 7.5f - 2.5f*sqrt2;  BEZIER_OFFSET_X_INTERCEPT = 7.5f*sqrt2 - 21
BEZIER_OFFSET_X_MAX_FACTOR = 1.5f;  BEZIER_OFFSET_X_MIN_FACTOR = 0.5f*sqrt2;  ...
dotSize   = R.dimen.coui_page_indicator_dot_size
dotSpacing= R.dimen.coui_page_indicator_dot_spacing
traceAnimator: ValueAnimator 240ms, PathInterpolator(0.25f, 0.1f, 0.25f, 1.0f)
```
工作方式：拖动时当前点被"拉出"一条与相邻点之间的贝塞尔粘性路径（`calculateTangentBezierPath / calculateControlPointOffset / mPortStickyPath / mDepartStickyPath`），松手 `startTraceAnimator` 240ms 弹回/吸附（`snapToPosition/verifyFinalPosition/verifyStickyPosition`）；圆点用 `R.layout.coui_page_indicator_dot_layout` + `R.drawable.coui_page_indicator_dot(_stroke)`；attr（styleable `COUIPageIndicator`）：`traceDotColor/dotColor/dotSize/dotSpacing/dotCornerRadius/dotClickable/dotIsStrokeStyle/dotStrokeWidth`；支持 RTL、点击跳页（`setOnDotClickListener`）。

### 附：COUIIPagerIndicator（`com.coui.appcompat.indicator`）
3 方法接口：`onPageScrolled/onPageSelected/onPageScrollStateChanged`，自绘指示器的规范接口。

**KMP 移植要点**：Banner=横滑 Pager + 自动轮播 + 双翼 expand（`fresh页面宽 = 屏宽 - 2*(sideWidth+margin)`）；液态指示器在 Compose 用两点间贝塞尔 Path + `Animatable` 240ms 恢复即可，常量齐全。
