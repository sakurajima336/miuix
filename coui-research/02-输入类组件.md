# 02 · 输入类组件（文本输入与选择输入）逆向报告

## ① 扫描范围与方法

- **APK**：`电话_17.6.5.apk`（21MB，edittext/searchview/input 深挖主力）、`Contacts_17.20.80.apk`（89MB，chip/picker/autocomplete/card-input/lockscreen-input/searchbar 深挖主力）、`oplus-fw-dex-probe.apk`（5MB，框架层 `android.app.COUIColorPickerUtils`）。
- **包前缀**：`com.coui.appcompat.edittext`、`com.coui.appcompat.input`、`com.coui.appcompat.autocomplete`、`com.coui.appcompat.searchview`（含 `.params`、`.params.olivelink`）、`com.coui.appcompat.chip`、`com.coui.appcompat.picker`、`android.app.COUIColorPickerUtils`。
- **方法**：先对 `recon/<apk>.classes.json` 做零成本 grep 锁定类清单；再用 REA `inspect-android-class` 拿成员清单（9+ 个类），`inspect-android-method` 反编译关键方法 Java 源码（20+ 个方法，含 `<clinit>` smali 回退）。所有结论均来自本次实际反编译输出，存于 `recon/out/`。
- **限制**：`decode-android-resources` 因本机无 apktool 失败（`REA_APKTOOL_NOT_FOUND`），attr/dimen 资源名除源码中直接出现 `R$dimen.coui_code_input_*` 外均以混淆名（`fc.l.B` 等）记录，值标"未确认"。大类 `<clinit>` 反编译引擎反复报错（`COUIChipDrawable`/`COUIChipTab`/`COUIChipGroup`/`COUINumberPicker`/`COUISearchViewAnimate`/`COUIColorPickerUtils`），常量值从字段名与使用处推断的均标注。

**coui-core 对照基准**：`coui-core/src/commonMain/kotlin/io/github/wfc35286/coui/kmp/component/` 现有 37 个文件（CouiButton/CouiText/CouiSwitch/CouiSeekBar/CouiToolbar 等），`find -iname "*edit*|*search*|*chip*|*picker*|*input*|*code*"` 结果为空——**以下全部组件均为 coui-core 不存在的新组件**。

## ② 文本输入类

### 2.1 COUIEditText —— 浮动标签（box）输入框 ⭐ 核心基建

- **类名**：`com.coui.appcompat.edittext.COUIEditText`（继承 TextView），所在 APK：全部含 COUI 的 APK（电话/Contacts/设置/Gallery/软件商店/设备互联/投屏）。
- **同包相关类**：`edittext.b`（绘制助手，onDraw 全部委托给它）、`edittext.a` / `edittext.a$a`（圆角 box 背景 drawable，带 `setCornerRadii`）、`COUICutoutDrawable`（hint 挖孔背景）、`COUIErrorEditTextHelper`（错误态助手）、`COUIEditFastDeleteWatcher`、`CustomEditTextSpan`、`RegexUtils`、`COUICollectionUtil`；内部类 12 个（`COUIEditText.a`~`l`，动画更新监听器等）。

**功能**：Material TextInputLayout 风格的单输入框，直接继承 TextView 实现：浮动 top-hint、box 背景（描边/圆角）、右侧删除图标（带 250ms 透明度动画）、错误色、无省略号滚动绘制（no-ellipsis）、长按/触摸反馈。

**box 背景装配**（`edittext.b.t(int,int,int,float[],a$a)`）：记录 textColors/highlightColor → `new com.coui.appcompat.edittext.a()` + `setCornerRadii(fArr)` → 注册 TextWatcher → 绑定焦点/错误状态机（`K()/M(c0086a)`）。

**视觉/交互细节**：删除图标 250ms alpha 淡入淡出；两条 PathInterpolator（0,0,0.1,1 标准减速 / 0.3,0,0.1,1 强调减速）；box 模式 2 时 hint 字重 sans-serif-medium；描边三色（default/focus `Q`/error `S`）各建独立 Paint（`x()` 中 `f8442g0`/`f8444h0`/`f8440f0`）。

**与 coui-core 对照**：无对应物。CouiText 只是文本，CouiButton 无编辑能力。**强烈建议移植**——它是 COUI 所有输入类组件（InputView/CardInput/CodeInput/SearchView/ChipGroupEditText/LockScreenPwd）的底座。
**KMP 要点**：Compose 中用 `BasicTextField` + 自绘 box 边框；浮动 hint 用 `animateDpAsState` + `PathInterpolator(0f,0f,0.1f,1f)` 转 CubicBezierEasing(0.0,0.0,0.1,1.0)（coui-core 的 CouiEasing 可直接复用）；删除图标 alpha 用 `animateFloatAsState(250ms)`；no-ellipsis 滚动可用 `drawWithContent` + scroll offset 实现。

### 3.6 android.app.COUIColorPickerUtils —— 框架层取色工具
