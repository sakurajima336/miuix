## ② 新组件明细

### 2.1 状态指示引擎：`com.coui.appcompat.state`（18 类）★ 本分类最高价值

这是所有 COUI 按钮/勾选/卡片触摸效果共用的底层状态机 + 弹簧遮罩动画引擎，coui-core 完全没有对应物（coui-core 的 `CouiPressFeedback` 只覆盖了其中"按压缩放"一小部分）。

#### 2.1.1 `StatefulDrawable` / `DrawableStateManager` / `DrawableStateProxy` — 触摸状态机

- 类名：`com.coui.appcompat.state.StatefulDrawable`（抽象，构造参数 `StatefulDrawable(String tag)`）、`DrawableStateManager`（`ctor(String, DrawableStateProxy)`）、`DrawableStateProxy`（接口）。
- 状态位（`DrawableStateProxy` 字段）：`STATE_PRESSED_FLAG / STATE_TOUCH_ENTERED_FLAG / STATE_FOCUSED_FLAG / STATE_HOVERED_FLAG / STATE_SELECTED_FLAG / STATE_ENABLED_FLAG`，触摸类型 `TOUCH_TYPE_PRESSED / TOUCH_TYPE_SELECTED`。
- 关键方法（`StatefulDrawable`）：`setTouchEntered()/setTouchExited()/setTouchSelectEntered()/setTouchSelectExited()/setFocusEntered()/setHoverEntered()/setSelectedEntered()/setStateLocked(int,boolean,boolean,boolean)`。
- 状态回灌（`DrawableStateManager.onStateChange`，反编译源码）：

```java
public void onStateChange(int[] iArr) {
    if (isNativeStateEnabled(32))  checkOnViewStateChanged(iArr, 16842910); // state_enabled
    if (isNativeStateEnabled(2))   checkOnViewStateChanged(iArr, 16842908); // state_focused
    if (isNativeStateEnabled(4))   checkOnViewStateChanged(iArr, 16843623); // state_hovered
    if (isNativeStateEnabled(8))   checkOnViewStateChanged(iArr, 16842913); // state_selected
    if (isNativeStateEnabled(16))  checkOnViewStateChanged(iArr, 16842919); // state_pressed
}
```

即原生 View drawable state → 内部触摸状态位的映射；`setStateLocked` 允许外部代码锁定某个状态位（如 FAB 菜单展开时锁定 touch-enter）。

- `RippleStatefulDrawable` 是 `StatefulDrawable` 的 RippleDrawable 变体（成员完全同构）。

#### 2.1.2 `StateEffectAnimator` — 弹簧驱动的遮罩进度动画（单通道）

- 构造：`StateEffectAnimator(Drawable hostDrawable, View hostView, String tag, int startMaskColor, int endMaskColor)`（另有两个简化重载）。
- 核心字段：`mSpringAnimation: COUISpringAnimation`、`mMaskTransition: FloatPropertyCompat<StateEffectAnimator>`（属性名即 tag，如 "hover"/"focus"/"press"）、`mCurrentAnimatedValue`、`mStartMaskColor/mEndMaskColor`、`mPendingThresholdValue`。
- `ensureSpringAnimation()`（反编译）：

```java
private void ensureSpringAnimation() {
    if (this.mSpringAnimation != null) return;
    COUISpringAnimation anim = new COUISpringAnimation(this, this.mMaskTransition);
    this.mSpringAnimation = anim;
    anim.setSpring(new COUISpringForce());
}
```

- `animateToProgress(float, boolean)`：`z=true` 时 `setStartValue(当前值)` + `animateToFinalPosition(target)`（连续弹簧追踪）；`z=false` 时若弹簧在跑先 `reset()` 再直接 `setProgress(target)`（跳变）。
- 其余 API：`animateToProgressFrom(from, to, animate)`、`animateToProgressUntil(target, threshold)`、`setSpringResponse(float)`、`setSpringBounce(float)`、`getCurrentMaskColor()`（ArgbEvaluator 在 start/end 颜色间按 progress 插值）、`getCurrentAnimatedFraction()`。
- 结束自动回弹：ctor 中挂 `mResetEndListener`，动画结束时回调 `animateToProgress(0.0f, true)` —— 松手后遮罩弹簧归零。

#### 2.1.3 `COUIMaskEffectDrawable` — hover/focus/press 三通道弹簧遮罩

- 构造 `COUIMaskEffectDrawable(Context, int maskType)`（反编译，这是整个引擎最核心的一段）：

```java
public COUIMaskEffectDrawable(Context context, int i) {
    ...
    this.mMaskType = i;
    this.mHoverAnimator = new StateEffectAnimator(this, "hover", 0, COUIContextUtil.getAttrColor(context, R$attr.couiColorHover));
    this.mFocusAnimator = new StateEffectAnimator(this, "focus", 0, COUIContextUtil.getAttrColor(context, R$attr.couiColorFocus));
    this.mPressAnimator = new StateEffectAnimator(this, "press", 0, COUIContextUtil.getAttrColor(context, R$attr.couiColorPress));
    this.mHoverAnimator.setSpringResponse(0.3f);  this.mHoverAnimator.setSpringBounce(0.0f);
    this.mFocusAnimator.setSpringResponse(0.3f);  this.mFocusAnimator.setSpringBounce(0.0f);
    this.mPressAnimator.setSpringResponse(0.3f);  this.mPressAnimator.setSpringBounce(0.0f);
}
```

- **视觉参数**：遮罩颜色从透明(0)弹簧过渡到主题语义色 `couiColorHover` / `couiColorFocus` / `couiColorPress`（attr，运行时取值）；弹簧 `response=0.3f`、`bounce=0f`（临界阻尼，无过冲）。颜色合成：`getCompositeMaskColor()` = `ColorUtils.compositeColors(press, compositeColors(focus, hover))`。
- 两种遮罩类型（`setMaskType` / `draw`）：`MASK_EFFECT_TYPE_WIDGET_WITH_BACKGROUND(0)`（画 hover+press，用于自身有背景的控件）、`MASK_EFFECT_TYPE_CONTAINER_WIDGET(1)`（容器件）。遮罩形状：`setMaskPath(Path)` / `setMaskRect(RectF, radiusX, radiusY)`，缺省圆角矩形（`drawPathOrRect` 取 bounds 的 `min(w,h)/2` 圆角）。
- 触摸进入最小进度门槛 `setMinProgressForTouchEnterAnimation(float 0..1)`（字段 `DEFAULT_MIN_PROGRESS_FOR_TOUCH_ENTER_ANIMATION`，具体值未确认——静态 final 内联）。
- 状态开关：`enablePressedState/enableHoverState/enableFocusedState/enableSelectedState(boolean)`、`setStateLocked`、`setAnimateEnabled`。

#### 2.1.4 `COUIMaskRippleDrawable` — 圆形波纹遮罩（继承 RippleDrawable）

- 构造 `(Context)`；字段含 `mFocusAnimator / mHoverAnimator / mRadius / mRippleMaskType`。
- 波纹半径类型（`getMaskRippleRadiusByType(Context, int)`）：

```java
if (i == 0) return res.getDimensionPixelOffset(R$dimen.icon_ripple_bg_radius);      // 24dp
if (i == 1) return res.getDimensionPixelOffset(R$dimen.checkbox_ripple_bg_radius);  // 20dp
```

（aapt2 实测：`dimen/icon_ripple_bg_radius=24dp`、`dimen/checkbox_ripple_bg_radius=20dp`。）
- `setCircleRippleMask(int radius)` → `mRippleMaskType=0`（圆形，`drawCircle(center, mRadius)`）；`setCustomRippleMask()` → `mRippleMaskType=1`（path/rect 遮罩 + `clipPathOrRect` 裁剪）。
- `draw(Canvas)`（反编译）：先画 hover 遮罩色、再画 focus 遮罩色，然后 `super.draw()`（原生 RippleDrawable 波纹），custom path 时整体 clip。
- 状态集合常量：`PRESS_ENTERED_STATE_SET={state_enabled, state_pressed}`、`PRESS_EXITED_STATE_SET={state_enabled}`（clinit smali：0x101009e=state_enabled、0x10100a7=state_pressed）。
- `refresh(Context)`：`mHoverAnimator.setEndMaskColor(attr couiColorHover)`、`mFocusAnimator.setEndMaskColor(attr couiColorFocus)`、`setColor(attr couiColorPress)`。

#### 2.1.5 `COUIStateEffectDrawable` — 状态效果组合容器

- 构造：`COUIStateEffectDrawable(Drawable[] layers)`。职责：把「View 原背景 + COUIMaskRippleDrawable/COUIMaskEffectDrawable」打包成一个 `setBackground()` 可用的 Drawable，并转发状态。
- 扩展能力：`enableScaleEffect(View[, int])` / `disableScaleEffect()`（内部 `mScaleHelper: com.coui.appcompat.pressfeedback.COUIPressFeedbackHelper` —— 按压缩放叠加）、`setTouched/setFocused/setHovered/setTouchSelected(boolean)`、`setStateLocked`、`setViewBackground(Drawable)`。
- 典型组装（`COUICheckBox.configStateEffectBackground` 反编译）：

```java
COUIMaskRippleDrawable ripple = new COUIMaskRippleDrawable(getContext());
ripple.setCircleRippleMask(COUIMaskRippleDrawable.getMaskRippleRadiusByType(getContext(), 1)); // 20dp
COUIStateEffectDrawable bg = new COUIStateEffectDrawable(
        new Drawable[]{ getBackground()==null ? new ColorDrawable(0) : getBackground(), ripple });
super.setBackground(bg);
COUIDarkModeUtil.setForceDarkAllow(this, false);
```

#### 2.1.6 `COUIStrokeDrawable`、`COUIViewStateController` + Processor 家族

- `COUIStrokeDrawable(Context)`：描边效果 drawable，`draw/draw` 由 `COUIButton` 等以 `COUIMaterialEffect` 参数驱动（`COUIStrokeDrawable` 仅是宿主，参数在 `COUIMaterialStrokeEffect$StrokeEffectParams`）。
- `COUIViewStateController`：`SparseArray<List<Processor>>`，`addViewStateProcessor(List<Processor>)` + `onViewStateChanged(int)` 按 key 分发；`MarginProcessor/PaddingProcessor/SizeProcessor/TextSizeProcessor` 都是 `Processor<V, T>` 子类，用 `SparseArray<T>` 存「状态→值」映射，`Builder` 模式构建（如 `MarginProcessor.Builder` 的 KEY_START/END/TOP/BOTTOM_MARGIN）。`SingleButtonWrap.getLargeProcessor/getMediumProcessor/getSmallProcessor` 即用它们在小屏/大屏状态间切换按钮内边距、尺寸、字号。
- `StatefulDrawableListener`：单方法 `onDrawableUpdate()`。

**与 coui-core 对照**：coui-core 的 `motion/CouiPressFeedback`、`CouiInteraction` 已有"按压缩放 + mask 进度"雏形，但缺：① hover/focus/press 三通道独立弹簧遮罩与语义色；② `setStateLocked` 状态锁；③ 复合遮罩色合成；④ Processor 式"状态→尺寸/边距/字号"切换器。**值得移植**，建议以 `CouiStateEffectModifier` + `CouiStateAnimator(response=0.3, bounce=0)` 落地。

**KMP 移植要点**：`StateEffectAnimator` ≈ Compose 里 `Animatable(0f, spring(dampingRatio=1f, stiffness≈ 1/response² 标定))`；三个通道各一个 `Animatable`，`drawWithContent` 里按合成顺序画三张遮罩；`MaskRipple` 对应 `Modifier.border`+圆形 clip+ripple 的组合。

### 2.2 按钮变体：`com.coui.appcompat.button`（9 类）+ `buttonBar`（1 类）

coui-core 已有 `CouiButton`（ButtonType/Large/Small/按压反馈已建模），以下是**尚不存在**的变体：

#### 2.2.1 `COUILoadingButton`（extends COUIButton）— 加载态按钮 ★

- 状态机：`DEFAULT_STATE=0` / `LOADING_STATE=1`（字段 `mButtonState`），API：`switchToLoadingState()` / `resetButtonState()` / `getButtonState()`，回调 `OnLoadingStateChangeListener.OnLoadingStateChanged(int)`。
- 两种加载视觉（`mShowLoadingText` 由 attr `COUIButton_isShowLoadingText` 控制，loading 文案 attr `COUIButton_loadingText`）：
  1. **文字+点**：`mDots = getString(R.string.loading_button_dots)`，`onDraw` 里测量 `mLoadingText + mDots`，若超宽自动降级为圆点模式；用 `drawClipDot`（clipRect 逐点裁剪绘制 "..."，三个点各自 alpha）。
  2. **纯圆点**：`drawLoadingCircles` 画 3 个圆，圆心 y=view 高度一半，起点 `x=(w-mLoadingCircleTotalWidth)/2 + r`，间距 `r*2+spacing`。
- 尺寸（aapt2 实测）：`dimen/coui_loading_btn_circle_radius=1dp`、`coui_loading_btn_circle_spacing=2dp`；`mLoadingCircleTotalWidth = r*6 + spacing*2`（ctor）。
- 三点 alpha 波形（`initAnim` 反编译，每点 4 段 ValueAnimator、AnimatorSet.playTogether + COUILinearInterpolator，循环重启 via onAnimationEnd→post(start)）：

```java
// dot1: 51→MID_ALPHA 133ms @0ms; MID→END 67ms @133ms; END→MID 67ms @467ms; MID→51 133ms @533ms
// dot2 同波形 @333ms 起（0.333s 相位差）; dot3 @666ms 起
// 周期 = 1332ms; resetButtonState 后三点 alpha 复位为 51
```

  常量 `DOT_MID_ALPHA / DOT_END_ALPHA` 为静态 final 内联，**数值未确认**（clinit 未见，源码中为编译期常量）。初始 alpha=51（0.2）。
- `switchToLoadingState()`：`setText("")` + `mLoadingAnim.start()`；`resetButtonState()`：`setText(mOriginalText)` + cancel + 复位 alpha + 回调。文本变化监听 `initTextChangeListener()` 同步 `mOriginalText`。
- 关联 attr：`loadingButtonNeedVibrate`、`isShowLoadingText`、`loadingText`、`text_in_loading`（主题 `Widget.COUI.COUILoadProgress` 亦引用）。
- **与 coui-core 对照**：无对应物。**值得移植**（Compose：`CouiLoadingButton`，三点 alpha 用 `rememberInfiniteTransition` 的 keyframe：0-133-200-467-600-666ms 波形，周期 1332ms）。

#### 2.2.2 `COUIIconButton`（extends COUIButton）— 图标精排按钮

- 解决 COUI 按钮上 compound drawable 的**四方向精确定位**：重写 `getDrawableLeftXPosition/...Right/...Top/...Bottom + getCompoundPaddingLeft/Right/Top/Bottom`，另设独立 `iconPadding/iconPaddingLeft/...Bottom`（可不等同 text padding）。`onDraw` 内 `drawIcon(Drawable, Canvas, x, y)` 自绘。
- `DEF_ICON_PADDING` 常量 + Kotlin `Companion`。**KMP 对照**：相当于 `Button(contentPadding=…, content=Row(Icon,Text))` 的定制排布，可做 `CouiIconButton`（低优先级——Compose 下天然容易）。

#### 2.2.3 按钮组三件套：`COUIButtonLayout` + `SingleButtonWrap` + `SimpleButtonGroupCtrl`

- `COUIButtonLayout`（布局容器）：`onMeasure` 限制 `mMaxWidth/mMaxHeight`，`setOrientation` 横/竖切换，`mHorizontalLayoutPadding/mVerticalLayoutPadding`，`isForceSmallScreenWidth` 强制小屏形态，`OnButtonLayoutVisibilityChangedListener`。
- `SingleButtonWrap`（单按钮包装 + 状态处理器）：核心是** Processor 换装**——`getLargeProcessor/getCentralLargeProcessor/getMediumProcessor/getPanelMediumProcessor/getDescMediumProcessor/getSmallProcessor(Context)` 返回 `List<state.Processor>`（Margin/Padding/Size/TextSize），`setLargeButtonLines/setMediumButtonLines` 控制行数（`SINGLE_LINE/MULTI_LINE`，`BUTTON_MAX_LINE`），`onConfigurationChanged` 时 `reInProcessor()` 重新挂载。
- `SimpleButtonGroupCtrl`（组控制器）：`registerButton(COUIButton[, int])`、`adjustButtonWidths()`（等宽化）、`processSameSize()`、`handleExtraLongLogic(int, List<SingleButtonWrap>)`（超长文本降级）、`computeSmallScreenHorizontalSlotWidth(COUIButtonLayout)`（小屏横向槽宽）、`resetLayoutToHorizontal(Configuration)`。
- **与 coui-core 对照**：coui-core 只有 `CouiRowGroup`，没有"对话框按钮组的等宽/换行/小屏横竖切换"逻辑。**值得移植**为 `CouiButtonGroup`（中优先级）。

#### 2.2.4 `COUIButtonBarLayout` — 对话框按钮栏

- 丰富的对话框按钮栏：持 `mPosButton/mNegButton/mNeuButton`，`onFinishInflate` + `initChildView` 自动识别；`setDynamicLayout(boolean)`（文本超宽自动横→竖排，`needSetButVertical(int)` / `wouldButtonTextExceedWidth(Button,int)` + `mTextWidthCache` 文本宽度缓存）；推荐按钮机制 `setRecommendButtonId/setRecommendButtonType` + `applyRecommendStyle`；毛玻璃底 `setBlurBackgroundWindow(boolean)` + `getBlurWindowButtonType`；`applyViewClipExpandChainToViewAndAncestors`（COUI clip-expand 链）。
- 竖排模式下大量 padding 微调方法（`setVerButVerPadding/setVerButDividerVerMargin/setVerPaddingBottom…`）。
- **对照**：coui-core 弹窗系列（报告 01）若未含按钮栏布局，此项是其输入组件。中优先级。

#### 2.2.5 支撑类：`StrokeEffectCustomParams`、`DescButtonTextSpan`、`PopupGradientBackgroundHelper`

- `StrokeEffectCustomParams`：Kotlin data class，`lineWidth/lineAngle/lineAlpha/shadowFadeIn/shadowFadeOut/shadowFadeScale + BlendMode`——高光描边参数包。`COUIButton` 内置 6 组预设：`PRIMARY_DARK_ENABLED / PRIMARY_DISABLED / PRIMARY_LIGHT_ENABLED / SECONDARY_DARK / SECONDARY_LIGHT / TRANSPARENT_DARK / TRANSPARENT_LIGHT`（字段表实测），实际描边参数走 `COUIMaterialEffect.getStrokeParamsByType(ctx, StrokeEffectType.TYPE_CONTENT_CAPSULE_4/5/6)`（`getStrokeParams` 反编译：PRIMARY/AI_PAYMENT→TYPE_4，SECONDARY/AI_PAYMENT_SECONDARY→TYPE_5，TRANSPARENT→TYPE_6，disabled 用 *_DISABLED_* 变体）。coui-core 有 `CouiSpotLightShader` 但无描边高光参数集，可作为 token 补充。
- `DescButtonTextSpan(ReplacementSpan)`：按钮"主文案+小副文案"两段式文本（`setDescType(boolean, String)`），构造 `(Context, descText, …, textSize…, Paint, isRtl)`，`getSubStringByWidth` 按宽度截断。对应资源 `coui_btn_desc_text_size=16sp`、`coui_btn_desc_sub_text_size=10sp`、`coui_btn_desc_height_min=44dp`、`coui_btn_desc_padding_horizontal=12dp`、`coui_btn_desc_padding_vertical=4dp`（aapt2）。
- `PopupGradientBackgroundHelper`：弹窗按钮的渐变背景辅助（View attach/detach 驱动），与弹窗报告关联，此处仅登记。

### 2.3 悬浮按钮：`com.coui.appcompat.floatingactionbutton`（9 类）

coui-core **没有 FAB**（`CouiFloatingMaterial` 是底部悬浮条材质，不是 FAB）。

#### 2.3.1 `COUIFloatingButton` ★（核心，11 个匿名类 + 3 内部行为类）

- 结构：本体是容器，`createMainFab()` 产出 `AppCompatImageView mMainFloatingButton` + `FloatingButtonWrapper mMainButtonWrapper`（wrapper 里挂 `COUISpotLightEffectDrawable` 聚光），菜单子项为 `COUIFloatingButtonLabel` 列表（`mFloatingButtonLabelList`）。
- 状态机：`STATE_NORMAL=0 / STATE_EXPANDING=1 / STATE_EXPANDED=2 / STATE_COLLAPSING=3 / STATE_DISABLED=4`（字段实测顺序以常量为准），`setState(int): boolean`、`toggle(boolean,boolean,int,boolean)`、`openFloatingButtonMenu()/closeFloatingButtonMenu()` 三个重载（可带动画开关/时长/是否记录）。
- 菜单展开动画（`animationFloatingButtonMenuExpand(label, …)`）：子项位移动画 `ANIMATION_TYPE_TRANSLATION_Y/SCALE_X/SCALE_Y/ALPHA/ROTATION`，`ACTION_ANIM_DELAY` 级联延迟；关闭侧 `animationFloatingButtonMenuClose` + `DEFAULT_CLOSE_MENU_ANIMATION_DURATION_WITH_SLIDE_OUT`。主按钮旋转 `rotateForward(View, float, boolean)` / `rotateBackward(boolean): ObjectAnimator`，双插值器 `mRotateForwardInterpolator/mRotateBackwardInterpolator`，`DEFAULT_ROTATE_ANGLE`（无子项时 `DEFAULT_ROTATE_ANIMATION_DURATION_NO_ITEM`）。
- 弹簧参数：字段 `DEFAULT_SPRING_ANIMATION_DAMPING_RATIO / DEFAULT_SPRING_ANIMATION_STIFFNESS / DEFAULT_SPRING_ANIMATION_START_VELOCITY`（数值未确认——编译期常量内联）；位移增强 `mTranslateEnhancementRatio`。
- 按压反馈：`animatePress()`（反编译：`performHapticFeedback()` → cancel `mProgressAnimator` → 按状态锁 `mMaskDrawable.setTouchEnterStateLocked(true,true,true)` → `mProgressAnimator.start()`）；`animateNormal(MotionEvent)`：出界/抬手时解锁并按需 `closeFloatingButtonMenu()`。`mPressAnimationRecorder` ValueAnimator 实时记录 `mPressValue` 供中断续接（`mIsNeedToDelayCancelScaleAnim`）。
- 材质开关全套：`mIsMaterialBlurEnabled / mIsMaterialCausticShadowEnabled / mIsMaterialSpotlightEnabled / mIsMaterialStrokeEnabled` + `setBlurEffectEnable/setStrokeEffectEnable/setSpotlightEnabled`、`ensureBlurEffect/ensureStrokeEffect(boolean)`。
- 自动隐藏：`AutoDismissRunnable`、`mHideAnimator`、`setAutoSlideInDisable()`、滑入滑出 `animationFloatingButtonSlideIn(int)/SlideOut()`（`DEFAULT_SLIDING_THRESHOLD`、`MESSAGE_PAUSE_TIME_SLIDE_OUT`）。

### 2.4 进度与加载：`com.coui.appcompat.progressbar`（9 类）

coui-core 已有 `CouiSeekBar/CouiSectionSeekBar`（滑杆），但**进度条/加载指示全部缺失**。

#### 2.4.1 `COUIHorizontalProgressBar` — 水平进度条

- 直接自绘（非 ProgressBar 派生）：字段 `mProgressRect/mBackgroundRect/mProgressPath/mPath/mRadius/mStyle/mNeedRadius`，`onDraw` 画两圆角矩形；`onSizeChanged` 更新 path；`isLayoutRtl` 支持 RTL。
- 默认色（clinit smali 实测）：`DEFAULT_BACKGROUND_COLOR = Color.argb(12, 0,0,0)` = `#0C000000`；`DEFAULT_PROGRESS_COLOR = #FF2AD181`（绿色）。`mAttrArray = {R$attr.couiSeekBarProgressColorDisabled}` —— disabled 态取该 attr。
- 关联资源：`color/coui_progressbar_progress_selector`、`coui_progressbar_background_selector`（selector XML）；主题 `style/Widget.COUI.ProgressBar`：`progressHeight/progressWidth=48dp`、`maxHeight/maxWidth=48dp`、`indeterminateDuration=3500`、`indeterminateBehavior=1`。
- **移植优先级：高**（最常用的基础件）。

#### 2.4.2 `COUICircularProgressBar` + `COUICircularProgressDrawable` ★ — 可暂停/出错圆形进度

- View 层：类型 `TYPE_DEFAULT / TYPE_FOLLOW_THEME / TYPE_ON_IMAGE`（`setProgressBarType`），尺寸 `MEDIUM_SIZE / LARGE_SIZE`（`setProgressSize`）；颜色 attr `couiCircularProgressBarColor/couiCircularProgressBarTrackColor/couiCircularPauseDrawableTint/couiCircularErrorDrawableTint`（主题默认 `?attr/couiColorHintNeutral` / track `?attr/couiColorDivider`）；`pause()/resume()/error()/recover()/isPaused()/isError()` 状态机；`SavedState` + 无障碍 `AccessibilityEventSender`。
- 尺寸（aapt2）：`coui_circular_progress_default_length=40dp`、`default_padding=4dp`、`medium_length=30dp`、`medium_stroke_width=3dp`、`large_stroke_width=5dp`、`error_stroke_width=1.5dp`、`error_diameter=19dp`、`pause_icon_rect_width=4dp`、`pause_icon_rect_height=16dp`、`pause_icon_rect_radius=1dp`、`pause_icon_rect_gap=4dp`、`error_icon_circle_radius=1.1dp`、`error_icon_rect_width=1.6dp`、`error_icon_rect_height=5.25dp`、`shadow_radius=4dp`、`color/coui_circular_progress_shadow_color=#19000000`。
- Drawable 层是精华：**真实进度用弹簧追踪**（`initSpring` 反编译）：

```java
SpringForce springForce = new SpringForce();
springForce.setDampingRatio(1.0f);   // 临界阻尼
springForce.setStiffness(50.0f);
mSpringAnimation = new SpringAnimation(this, VISUAL_PROGRESS);  // FloatPropertyCompat "visualProgress"
mSpringAnimation.setSpring(springForce);
```

  `setProgress(int, boolean)` 设定目标，`actual2VisualProgress` 换算，`notifyActualProgressChanged/notifyVisualProgressChanged` 双通道通知（`OnProgressChangedListener`）。
- 暂停/恢复/出错四套动画（`initPauseAnimator/initResumeAnimator/initErrorAnimator/initRecoverAnimator`，均为 AnimatorSet）：进度环**放大缩小**（`mProgressEnlargeAnimator/mProgressShrinkAnimator`）+ 暂停图标（两根圆角矩形 `mPauseIconRect*`）或错误图标（圆+叉 `mErrorIconCircle*`）淡入淡出（`mIconPauseAnimator/mIconErrorAnimator/mIconRecoverAnimator`，alpha 动画 `ArgbEvaluator ColorEvaluator`）。常量：`DEFAULT_ICON_PAUSE_DURATION / DEFAULT_ICON_RESUME_DURATION / DEFAULT_ERROR_DURATION / DEFAULT_PROGRESS_PAUSE_DURATION / DEFAULT_PROGRESS_RESUME_DURATION / DEFAULT_DELAY / DEFAULT_MIN_PROGRESS_VALUE`（数值未确认）。
- 绘制（`drawProgress` 反编译）：track 全圆 + 进度弧 `-90°` 起始顺时针 `visualProgress*360/max`，进度环直径独立于 track（`mProgressProperty vs mTrackProperty` 各自 outerDiameter/strokeWidth）—— 支持环变粗变细动画；`mProgressBarAlpha != 255` 时 `saveLayerAlpha`；`setIsDrawShadow` 阴影（`mShadowRadius/mShadowXBias/mShadowYBias`）。
- 插值器：`DEFAULT_LINEAR_INTERPOLATOR=COUILinearInterpolator`、`DEFAULT_IN_EASE=COUIInEaseInterpolator`、`DEFAULT_OUT_EASE=COUIOutEaseInterpolator`、`DEFAULT_MOVE_EASE=COUIMoveEaseInterpolator`（clinit 实测）。
- **移植优先级：高**。Compose：`CouiCircularProgressBar`（`Animatable` + `spring(1f, 50f)`，pause/error overlay 用 crossfade）。

#### 2.4.3 `COUICircleProgressBar` — 简单圆环

- 成员：`drawBackgroudCicle/initBackgroundPaint/initProgressPaint/initArcRect`，无 pause/error；主题 `Widget.COUI.COUICircleProgressBar`：`couiCircleProgressBarColor=?attr/couiColorPrimary`、`BgCircleColor=?attr/couiColorSecondary`、宽高=`coui_loading_view_default_width/height`。是 2.4.2 的轻量版。

#### 2.4.4 `COUILoadingView` — 弧线旋转加载

- 三种尺寸 `SMALL_TYPE / MEDIUM_TYPE / LARGE_TYPE`，`setLoadingType(int)`；常量 `PROGRESS_POINT_COUNT / SWIPT_ANGEL / ONE_CYCLE_DURATION / STEP: mStepDegree`，`mPointsAlpha[]` 渐隐点阵（`LARGE_POINT_START/END_ALPHA、MEDIUM_POINT_START/END_ALPHA`），`createAnimator/startAnimations/cancelAnimations` 生命周期自动启停（attach/detach/visibility 全覆盖）。
