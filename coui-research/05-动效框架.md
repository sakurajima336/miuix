### A. `com.coui.animatekit`（oplus-services-dex-probe.apk）—— 官方 View 层动效 DSL 框架 ⭐ 全新

**子包结构**（来自 `recon/oplus-services-dex-probe.classes.json` 完整清单，共约 100 类）：
`core / curve / dsl / manager / modifier / option / state / strategy / target / util` + 根包 8 类（`DynamicAnimation`、`SpringAnimation`、`SpringForce`、`FlingAnimation`、`Force`、`FloatPropertyCompat`、`FloatValueHolder`、`COUIProperty`、`RSSpringModel*`）。

这是 ColorOS 把「View 属性动画 + 弹簧物理 + SurfaceControl 事务」统一成一套 **声明式 DSL** 的框架层，Kotlin 编写，API 形态与 Compose 动画高度同构。coui-core 中完全不存在，是 motion 包最有价值的移植对象。

#### A1. DSL 入口与链式编排（`dsl` 包）

**入口扩展函数**（`com.coui.animatekit.core.AnimExtensionKt`，来自类清单）：

```kotlin
fun View.animateTo(block: COUIViewAnimationDSLBuilder.() -> Unit): AnimationChain<View>
fun SurfaceControl.animateTo(block: COUISurfaceControlAnimationDSLBuilder.() -> Unit): AnimationChain<SurfaceControl>
fun <T> T.animateToGeneric(block: COUIAnimationDSLBuilder<T>.() -> Unit): AnimationChain<T>
```

**链式编排**（`com.coui.animatekit.dsl.AnimationChainKt`，类清单）：
- `then(...)`：串行追加（前一动画组结束后启动）；`with(...)`：并行同组；各留 `thenView / thenSurfaceControl / thenViewOn / thenViewToSurfaceControl / thenGenericOn` 等 26 个重载，**支持中途切换目标类型**（View ↔ SurfaceControl）。
- `AnimationChain` 字段：`animationGroups: List<AnimationGroup>`、`currentGroupIndex`、`isStarted`（类清单）。串行靠 `setupAnimationCompletionTracking(AnimationWithTarget, int)` 追踪完成时机（类清单）。

**串行组的启动**（`AnimationChain.start()`，反编译源码）：

```java
public final void start() {
    if (!this.isStarted) {
        this.isStarted = true;
        AnimationGroup firstGroup = this.animationGroups.get(0);
        for (Object element$iv : firstGroup.getAnimations()) {
            ((AnimationWithTarget) element$iv).runAnimation();
        }
    }
}
```

**串行组注册**（`AnimationChain.addNextAnimationGroup$animation_release`，反编译源码）：新建 `AnimationGroup`，`animationTarget == null` 时回落到链的主 target，然后 `setupAnimationCompletionTracking(...)`。

**通用 Builder**（`COUIAnimationDSLBuilder`，类清单）：

| 成员 | 说明 |
|---|---|
| `propertiesCommon(PropertiesBuilder<T, COUICommonCurve>.() -> Unit)` | 时间曲线属性组 |
| `propertiesSpring(PropertiesBuilder<T, COUISpringCurve>.() -> Unit)` | 弹簧属性组 |
| `property(COUIProperty<T>, from, to, IAnimCurve)` | 单属性直写 |

**Builder 编译期校验**（`COUIAnimationDSLBuilder.build()`，反编译源码关键段）：


**View 专用 Builder**（`COUIViewAnimationDSLBuilder`，类清单）：`alpha / translate / position / scale / rotate / scroll` 各 2~4 个重载，形如 `translate(tx, ty, curve)`（自动取当前值做起点）、`translate(fromX, fromY, toX, toY, curve)`、`scale(to, curve, pivotX, pivotY)`（带 pivot）。

**SurfaceControl 专用 Builder**（`COUISurfaceControlAnimationDSLBuilder`，类清单）：`alpha / translate / scale / bounds`；`bounds(...)` 重载直接传 `startBounds/endBounds + SurfaceControlScaleType`，并支持 `bindExternalTransactionIfNeeded` 外部事务绑定（字段 `externalTransaction`）。

**多属性 onUpdate 回调**（`PropertiesBuilder`，类清单）：`onUpdate2 .. onUpdate8`（目标 + 2~8 个 Float 的 lambda）与 `onUpdateMap(target, Map<String,Float>)` —— 一次动画驱动 2~8 个属性联动。

**执行体**：`COUIAnimationDSL.runOn(target)`（类清单）把 op 列表经 `util.AnimationBuilder.buildAnimationsFromOps(ops, target, endCallbackType, sceneName): AnimationSetResult` 编译成真实 `AnimatorSet / COUISpringAnimationSet`；`AnimationBuilder.buildSingleSpec / buildPairSpec / buildMultiSpec`（类清单）分别对应单属性/成对(XY)/多属性 Spec。`COUIAnimationDSL.createAndStartAnimationsOnThread(target)` 支持绑定 `customThreadHandler` 的自定义线程执行。

**结束回调语义**（`AnimationEndCallbackType` 枚举，类清单）：`LOGICALLY`（业务逻辑意义上的"结束"，供续接判断）与 `STOP`（被取消也回调）。

**与 coui-core 对照**：coui-core 的 motion 包只有数据层（CouiSpringData/CouiMotionTokens），没有任何执行编排层。这套 DSL（链式编排 + 曲线抽象 + op 编译）就是官方"Compose animate*AsState 之外"的命令式对应物。
**KMP 移植要点**：`AnimationChain.then/with` 可映射为 Compose 里的顺序/并行 `Animatable` 协程；`COUIAnimationDSLBuilder.build()` 的"混用曲线类型即抛异常"与"continueFrom 续接表"两个语义值得原样保留；`sceneName` 可映射为 Compose 的动画 label。

#### A2. 曲线系统（`curve` 包）—— response/bounce 与 Compose 完全同构

`IAnimCurve`（空接口，类清单）之下（`CurveType` 枚举 = `COMMON / SPRING`）：

- **`COUICommonCurve(duration: Long, interpolator: TimeInterpolator)`**（字段 `duration / interpolator`，类清单）—— 传统时长曲线。
- **`COUISpringCurve(stiffness, dampingRatio, blendDuration, startVelocity, isResponsive)`**（5 字段，类清单；`isResponsive` 即"响应式弹簧"，带 blendDuration）。

**工厂**（`Curves`，反编译源码）：

```java
// Curves.spring(float response, float bounce)
public static final COUISpringCurve spring(float response, float bounce) {
    return new COUISpringCurve(INSTANCE.responseToStiffness(response), 1.0f - bounce, 0.0f, 0.0f, false, 16, null);
}
// Curves.responsiveSpring(float response, float bounce, float blendDuration)
public static final COUISpringCurve responsiveSpring(float response, float bounce, float blendDuration) {
    return new COUISpringCurve(INSTANCE.responseToStiffness(response), 1.0f - bounce, blendDuration, 0.0f, true);
}
// Curves.responseToStiffness(float response)
private final float responseToStiffness(float response) {
    return (float) Math.pow(6.283185307179586d / (double) response, 2.0d);
}
```

即 **`stiffness = (2π / response)²`、`dampingRatio = 1 − bounce`** —— 与 coui-core `CouiSpring.kt:95` 的 `responseToStiffness()` 公式**逐字一致**（coui-core 已经移植了该换算）。另有 `linear/easeIn/easeOut/easeInOut(duration)` 与 `custom(duration, TimeInterpolator)`、`cubicBezier(duration, x1,y1,x2,y2)`（类清单）。

**与 coui-core 对照**：coui-core `CouiSpringData(bounce, response)` + `toSpringSpec()` 已覆盖普通弹簧；**缺 `blendDuration` 与 `startVelocity` 的 curve 化表达**（coui-core `CouiMotionTokens.kt:68` 只记了 `COUIResponsiveSpringMotion.DEFAULT_BLEND_DURATION = 250` 一个常量，没有 responsiveSpring 工厂本身）。
**移植要点**：给 `CouiSpringData` 增加 `blendDurationMs` 字段即可覆盖 `responsiveSpring`；`Curves` 工厂可直接写成 `CouiCurves` object。

#### A4. 隐式动画（`state.ImplicitAnimationBuilder` / `ImplicitAnimationKt`）—— `animate*AsState` 的 View 版

类清单：
- `ImplicitAnimationKt.animateOnStateChange(View, ImplicitAnimationBuilder.() -> Unit)` —— 对一个 View 声明隐式动画；
- `ImplicitAnimationBuilder.alpha(RememberStateDelegate<Float>)`、`scale(xState, yState)`、`translate(xState, yState)` —— 把状态委托绑定到属性；
- `ImplicitAnimationConfig(curve, onFinish)`、`ModifierConfig`（sealed：`ScaleWithState / TranslationWithState / AlphaWithState`）。

**绑定的实现**（`ImplicitAnimationBuilder.applyModifiers$animation_release`，反编译源码，alpha 分支）：

```java
COUIAlphaState state2 = new COUIAlphaState(StateDelegateKt.asState(config.getState()));
COUIAlphaModifier modifier3 = new COUIAlphaModifier(view, state2);
modifier3.applyImmediate(state2);

```

即：**每个绑定属性生成一个 modifier（见 A8），modifier 内部监听 State 变化并自动起动画**——语义就是 `animateFloatAsState`。

**与 coui-core 对照**：coui-core 有 `CouiStateMask`、`CouiPressFeedback`（都是手写 LaunchedEffect/Animatable），没有通用的"状态→属性"隐式动画声明。
**移植要点**：在 Compose 里这就是 `animateFloatAsState`，移植价值主要在 **默认曲线的统一入口**（builder 里统一设 `curve`）。

#### A6. 动画目标抽象（`target` 包）

#### A10. `RSSpringModel` —— 官方物理弹簧解析解（duration 可估算）⭐

根包 `com.coui.animatekit.RSSpringModel<T>`（泛型向量，`RSSpringModelFloat` 是 Float 特化，类清单）。字段：`response_ / dampingRatio_ / initialOffset_ / initialVelocity_ / minimumAmplitudeRatio_ / dampedAngularVelocity_ / coeffDecay_ / coeffScale_ / coeffDecayAlt_ / coeffScaleAlt_`。

**参数计算**（`CalculateSpringParameters()`，反编译源码）：

```java
this.dampingRatio_ = Math.max(SPRING_MIN_DAMPING_RATIO, Math.min(this.dampingRatio_, 10000.0f));
if (this.response_ <= 0.0f) this.response_ = SPRING_MIN_RESPONSE;
if (this.minimumAmplitudeRatio_ <= 0.0f) this.minimumAmplitudeRatio_ = 0.001f;
double naturalAngularVelocity = 6.283185307179586d / (double) this.response_;
if (dampingRatio < 1.0f) {           // 欠阻尼：衰减震荡
    dampedAngularVelocity_ = sqrt(1 - ζ²) * ω;
    coeffDecay_  = -ζ * ω;
    coeffScale_  = (v0 + x0·ζ·ω) / dampedAngularVelocity_;
} else if (ζ == 1.0f) {              // 临界
    coeffDecay_ = -ω;  coeffScale_ = v0 + x0·ω;
} else {                             // 过阻尼：双指数
    coeffTmp = sqrt(ζ² - 1);
    coeffDecay_ = (-ζ + coeffTmp) * ω;  coeffDecayAlt_ = (-ζ - coeffTmp) * ω;
    coeffScale_/coeffScaleAlt_ = 双指数系数;
}
```

**时长估算**（`estimateDuration()`，反编译源码）：

```java
float minimumAmplitude = Math.max(this.minimumAmplitudeRatio_ * initialOffset, SPRING_MIN_AMPLITUDE);
if (ζ < 1)      duration = ln(max(coeffScale, initialOffset) / minimumAmplitude) / (-coeffDecay_);
else if (ζ ==1) duration = response_ * 2.0f;
else            duration = max(主项, 备项);   // 两个指数项分别算 ln(幅度/最小可见幅度)/(-decay)
return Math.max(0.001f, Math.min(duration, 300.0f));   // 上限 300（秒? 单位未确认，SPRING_MAX_DURATION 值未确认）
```

这是标准二阶弹簧解析解（与 AOSP `SpringForce` 同族，RSSpringModel 是 AOSP `android.util` 系的泛型实现，但增加了 **estimateDuration**，可给"弹簧动画"提供可预估的时长用于事务/预测）。

**与 coui-core 对照**：coui-core `CouiSpring.kt` 已有同套 response→stiffness 换算和 `couiVelocityThreshold`，但 **没有 estimateDuration**。

**`PopupMotionAnimateKitBridgeUnit`**（类清单）：把 animatekit（"Kit"）动画桥接进 `COUIPopupTouchMotionAnimator` 单元体系 —— `bind(COUIComposeMotionAnimator) / contribute(ContributeSink) / syncPathFromKit(tx,ty) / syncAlphaFromKit / syncScaleFromKit`，并有 `viewRtDriveMask` 位掩码（`MASK_ALPHA / MASK_SCALE / MASK_TRANSLATION`）记录哪些属性由 RT 驱动，`isAnyViewRtPropertyActive()` 判定。

**`SpringProgressUnit / MenuTransitionUnit / SubMenuTransitionUnit / ParentInfluenceUnit`**（类清单）：菜单/子菜单过渡与父级影响单元；`SpringProgressUnit.ensureSpringAnimation` + `startAnimation(from, to, initialVelocity) / canSkipToEnd / skipToEnd`（类清单）是"进度弹簧"单元（coui-core `CouiPopupTouchMotion.kt` 已移植其下游视觉常量，见该文件 `CouiPopupTouchDefaults`）。

**与 coui-core 对照**：`CouiPopupTouchMotion.kt` 移植的是"触摸跟随/聚光"视觉；**open/dismiss 的三波次编排 + 贝塞尔弹道路径 + RT 混合写入是全新**。
**移植要点**：Compose 中三波次 = 三个并行 `Animatable`（scale/pathT/alpha）+ `joinAll`；路径进度用 E.`pointOnBezier(t)`；`PARALLEL_WAVE_COUNT` 等常量字面值未确认，需再挖 `runLegacyMainThreadWaves`（本会话列出但未反编译其函数体）。

## ④ KMP/Compose 移植优先级建议

1. **`Curves`/`COUISpringCurve` + `COUIResponsiveSpringMotion` 行为**（最薄、收益最大：给 `CouiSpringData` 加 `blendDuration` + `visibilityThreshold = Δ/10000` 默认）。
2. **`COUISwitchParams` 系弹簧默认值**（0.3/0.4/0.2 等）入 `CouiMotionTokens`。
3. **`BezierGravityPathMath` 弹道**（纯函数，直接搬）。
4. **`COUISpringDragHelper` 语义**（drag/attach 双弹簧 + 锚点吸附 + `getSpringApproximateOffset` 过冲）。
5. **续接机制**（`COUIAnimationContinuationManager`）—— Compose `Animatable` 天然具备，只需在 `animateTo` 前取 `value` 的规范固化下来。
6. **`RSSpringModel.estimateDuration`**（欠阻尼分支）用于手势预测。
7. animatekit 的 DSL/strategy/target/option 层**不建议按类移植**，但其语义（曲线类型一致性校验、`Float.MAX_VALUE` 哨兵、10ms 状态合并、SceneName 埋点）应成为 coui-core API 设计约束。
